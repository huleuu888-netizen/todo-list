# V15.18 Rock Permeability Inversion Plan

## Current Status
UNRESOLVED

## Objective
Establish an engineering-based calibration workflow for rock permeability parameters without changing parameters only to improve numerical convergence.

## Required Inputs
- Geological classification
- Field seepage monitoring data
- Piezometric observations
- Seepage discharge measurements

## Workflow
1. Define initial permeability range.
2. Compare numerical seepage response with monitoring data.
3. Perform parameter inversion.
4. Verify calibrated parameters before production cases.

## Rule
No artificial parameter modification before engineering verification.
