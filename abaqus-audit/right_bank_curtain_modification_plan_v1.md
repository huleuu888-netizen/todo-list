# S01 完整防渗体系闭合修改方案 v1

## 1. 修改目标

基于当前 V15.26 S01 设计对应性审计结果，不改变已验证通过的主河床防渗墙、左岸80 m延伸及现有网格体系，补齐原工程防渗体系中缺失的右岸灌浆帷幕，使 S01 基准模型完整对应工程防渗系统。

当前问题：

- 复合土工膜：已有对象，但需进一步确认是否需要等效复合层表达；
- 河床及左岸防渗墙：已通过审计；
- 左岸80 m延伸：已通过审计；
- 右岸灌浆帷幕：当前模型缺失；
- 防渗墙—土工膜—右岸帷幕连续连接：需要重新验证。

## 2. 修改原则

1. 不修改已经通过审计的主体防渗墙几何。
2. 不通过 Tie、弹簧、固定约束等方式人为连接缺失区域。
3. 新增右岸帷幕必须作为独立工程对象建立：
   - Part；
   - Instance；
   - Material；
   - Element Set。
4. 新增区域应与右岸岩体真实接触，并进行拓扑连续性检查。

## 3. 右岸帷幕建模方案

### 3.1 几何建立

根据工程资料确定：

- 帷幕起始位置：右岸防渗线与防渗墙连接位置；
- 延伸方向：向右岸山体内部延伸；
- 延伸长度：100 m；
- 深度、底高程及厚度：根据工程资料进一步确定。

若资料不足，不应自行假定，应标记参数待确认。

### 3.2 材料参数

建立独立帷幕材料，不直接修改右岸岩体材料。

建议结构：

- Material: RIGHT_BANK_CURTAIN
- Permeability: 采用工程资料给定值；
- 若无明确参数，设置为待标定参数，不用于最终结果。

## 4. 网格修改

仅局部重构右岸区域：

检查：

- 单元质量；
- 正负体积；
- duplicate elements；
- hanging nodes；
- 非协调面；
- 岩体—帷幕接口连续性。

保持 S01 baseline 不被覆盖，生成新的闭合版本：

S01_FINAL_DESIGN_CLOSED。

## 5. 验证流程

修改后依次执行：

1. Design correspondence audit
2. Geometry readiness audit
3. Material mapping audit
4. Connectivity audit
5. Abaqus Data Check
6. S01 baseline seepage analysis

只有以上步骤通过后，才进入 S02 防渗方案优化。

## 6. 后续 S02 设计建议

完成 S01 闭合后，S02 不建议直接做退化分析，应首先开展防渗方案比选：

- 方案A：原设计方案（基准）；
- 方案B：防渗墙深度优化；
- 方案C：右岸帷幕长度优化；
- 方案D：防渗墙—帷幕组合优化。

通过渗流量、水头分布及局部水力梯度确定优选方案。
