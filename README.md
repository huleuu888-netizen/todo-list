# Todo List

一个无需构建即可运行的响应式 Todo List 页面，使用原生 HTML、CSS 和 JavaScript 开发。

## 功能

- 新增待办任务
- 为任务设置、修改或清除截止日期
- 自动标记今天截止和已逾期的任务
- 标记完成 / 取消完成
- 全部、进行中、已完成筛选
- 删除单个任务
- 一键清除已完成任务
- 完成率统计
- 使用 `localStorage` 自动保存数据
- 响应式布局，支持桌面与移动端

## 使用方式

直接打开 `index.html` 即可使用。

也可以将仓库部署到任意静态托管服务，例如 GitHub Pages、Vercel 或 Netlify。
